# Topic 1B: Inputs and Outputs

> Study notes summarized in our own words. Not verbatim course text. Single scrollable page.

## Key points
- Four core workflow elements: **prompt** (initial written direction), **input** (data supplied: text/images/audio/video), **output** (generated result), **parameter** (optional setting like length, style, format).
- Text inputs use action keywords: generate, translate, summarize, describe, explain, outline, paraphrase, rewrite. Audio/video/image inputs each pair a sample file with a natural-language instruction.
- Output types mirror input modalities:
  - Text: stories, essays, poems, lyrics, code, equations.
  - Audio: music, sound effects, speech, enhancement.
  - Video: animation, synthesis, style transfer, captioning, effects.
  - Image: illustrations, digital art, 3D models, photo edits.
- **Multimodal outputs** combine several inputs — e.g., text+audio for a music video, text+images for a comic book, video+audio for an animated short.
- Customization options: custom GPTs/Gems/Copilots with fixed instructions, tone, safety rules, approved document access, and step-by-step workflows; **AI agents** execute structured multi-step sequences.
- Tool-selection factors: purpose/scope, ease of use, cost/access model, update cadence, data privacy/security, output quality/control, performance constraints, content policies.
- Text-model landscape: ChatGPT (coherent human-like conversation), Grok, Gemini, Claude, Llama, Jasper, KoalaWriter, DeepSeek — each with distinct strengths/weaknesses.
- Image models train on large image datasets; video models include Sora, Runway Gen-2, Pictory with differing strengths/weaknesses.
- Embedded knowledge checks appear after sections.
