# Answer Key

## ⭐ Question 1

1. The first blank → **Style**
2. The second blank → **Tone**

The style indicated in an AI prompt helps to shape the grammar used in the output. The tone indicated in an AI prompt sets the mood of the output.

## Question 2

**Correct answer:** The prompt needs context.

The problem with "Tell me about panthers." is that it does not provide any context for what type of panther should be described. The answer could describe the animal known as a panther, or it could refer to a sports team, such as the Carolina Panthers in football or the Florida Panthers in hockey. Adding a style or style guide won't help put any context into the prompt. Adding a persona or role, such as "As an animal specialist, tell me about Panthers," can help, but is not the underlying problem of the prompt not having any context.

## Question 3

**Correct answer:** Explain how XML files are used to configure Learning Management Systems.

The best prompt is one that does not have abbreviations or acronyms that could be construed for something else. Learning Management Systems should not use an acronym because LMS can also mean Lightning Message Service, which also uses XML files for configuration purposes. Words like configure should not be abbreviated, so whole words should be used whenever possible. One should not ask for a specific LMS to be configured unless the LMS uses a known format, like SCORM, to structure data.

## Question 4

**Correct answer:** Include style, pacing, visuals, and a clearly structured script.

## Question 5

**Correct answer:** As a high-energy martial arts instructor, describe the benefits of taking martial arts courses at your studio.

Adding a persona means putting the output in the frame of a different person, such as a martial arts instructor, and including emotion. A role added to a prompt does not include emotion, hence "high-energy martial arts instructor" better fits a persona than "martial arts instructor." Just having high energy sets a tone but does not add a persona. Just asking for benefits does not add a persona.

## Question 6

**Correct answer:** A reference to a style guide

A reference to a style guide, like the Microsoft Style Guide or the Associated Press (AP) Style Guide, should be included in each prompt to help ensure consistent grammar, spelling, and word choice among the articles. Adding a persona will help the tone of each output, but not the grammar, spelling, or word choice. Adding a role will help outputs stylistically, but not the grammar, spelling, or word choice. A glossary helps with the translation of data into the proper context in other languages.

## ⭐ Question 7

1. Adding context to an AI prompt will help produce a better output. → **Yes**
2. It's safe to assume that an AI engine will know what you are talking about. → **No**
3. Giving an AI prompt a persona does not affect the output. → **No**

It is not safe to assume that an AI engine will know what you are talking about. Giving an AI prompt a persona absolutely affects output, even for something as simple as going from first person to third person for wording results.

## Question 8

1. Write code that will generate a random number. → **Zero-shot**
2. Write code that will generate a random number between 1 and 10. → **One-shot**
3. Write code that will generate a random number between two previously generated random numbers. → **Few-shot**

A prompt with no example is a zero-shot prompt. A prompt with one example is a one-shot prompt. A prompt with a few examples is a few-shot prompt.

## Question 9

1. Adding documents to use for research. → **Yes**
2. Referencing an earlier conversation in the same thread. → **Yes**
3. Asking for a summarization. → **No**

Asking for a summarization narrows down an output rather than allowing for a more targeted output.

## Question 10

**Correct answer:** A glossary.

A glossary can aid in ensuring words are translated in the proper context. A style guide aids in the presentation of content, not in its translation. Assigning a role to the prompt will not aid in its translation. Providing a template will also be of no use in translation.

## Question 11

**Correct answer:** Helps create reusable prompts for brand-consistent content production.

## Question 12

**Correct answer:** Giving the AI an output and asking what prompt produced it.

## Question 13

**Correct answer:** Template.

A template allows for an output to have the same content, multiple times, with square brackets used for customized pieces. Mail Merge is used in Microsoft Word, not in Generative AI. An AI prompt can initiate a connection to a database, but that would mean a prompt is not staying strictly within an AI tool to produce an output. An Application Programming Interface (API) can be used, but again, it would make the AI tool reach outside itself to obtain data to produce an output.

## Question 14

**Correct answer:** Build a marketing flyer for a dog grooming business. Examples include "groom to bloom" and "doggie waggie."

This prompt has multiple examples, hence it is a few-shot prompt. Just telling AI to build a marketing flyer is an example of a zero-shot prompt. Telling AI to build a marketing flyer to include the word "shine" is an example of a one-shot prompt. Telling AI some words without asking it to build something is an example of fine-tuning.

## ⭐ Question 15

**Correct answer:** The final outcome or target result expected from the AI's task.

## Question 16

1. Self-consistency → **Yes**
2. Zero-shot → **No**
3. Few-shot → **No**
4. Generate knowledge → **No**

Self-consistency is a prompting technique in which the same prompt is run multiple times and the results, often different, are used to get a baseline of consistency among the results. Zero-shot is a prompting technique used with no prior references. Few-shot prompting is a prompting technique used with a few examples to try to get more accurate results. Generate knowledge is a prompting technique in which background information is given before a specific question is answered, which leads to more accurate responses.

## Question 17

**Correct answer:** Define glassblowing. Then tell me how it is used to make coke bottles.

A generate knowledge prompt asks for general knowledge on a subject and then for something specific on that subject. Breaking down steps is an example of chain-of-thought prompting. Just asking for something without any context is an example of zero-shot prompting. Asking for content with some guidance is an example of few-shot prompting.

## Question 18

**Correct answer:** Chain-of-thought

Chain-of-thought prompting involves conceptualizing an outline, reviewing the outline, and then reviewing a paragraph. Iterative refinement generates an initial response and then refines it through a series of prompts that make the output more detailed. Recursive prompting uses an output as an input for further prompting. Decomposition prompting breaks a task into smaller tasks.

## Question 19

1. I am interviewing someone for a graphics design position. What three interview questions should I start with? → **Yes**
2. If I want to improve my team meetings, what specific tips would you give? → **Yes**
3. Which database system would be best to use for data requiring a high amount of statistical analysis? → **No**

In reverse prompting, the prompt starts with a known end result and works backward. The example of asking which database system to use is not an example of a known end result, hence the prompt is not using reverse prompting.
