# Answer Key

## Question 1

1. Indicating what food is in the house should be part of the prompt. → **Yes**
2. Having an idea of what meal is wanted should be part of the prompt. → **Yes**
3. Asking what is needed at the store should be part of the prompt. → **No**

If the goal of the output is to show a recipe given what food is in the house, indicating what is needed at the store is not relevant information and should not be part of the prompt.

## Question 2

**Correct answer:** Write Python code that will generate a random number.

Prompts should be written in the affirmative, specific to what one needs. If the language is not specified, one will either see code for many languages or will be prompted to enter a language. The prompt does not require a specific range for a random number.

## Question 3

1. This type of summarization pulls the most important sentences from a report or book. → **Extractive**
2. This type of summarization paraphrases text from a report or book into a summary. → **Abstractive**

Query-based summarization provides answers to specific questions about a report or book.

## Question 4

1. Draft an AUP for a school district. → **Yes**
2. Give me some resume and interview tips for a school district position. → **Yes**
3. Write a story about a new school building opening. → **Yes**
4. Show me the exact AUP from a school district. → **No**

Generative AI is not going to reveal a proprietary document from an organization.

## Question 5

**Correct answers:** Show an example related to house building; Explain the opposite of a cosine at a 9th grade level.

Adapting content to a grade level is a common method used to make concepts understandable. Providing a practical example of a concept also makes it understandable. Merely asking a question does not give context for personalization or adaptation, and just asking for an example may not provide enough personalization or adaptation.

## Question 6

1. Editing and proofreading documents. → **Format the output using the AP Style Guide.**
2. Providing a visualization of data. → **Show this region's population trends as a chart.**
3. Transforming content into a different media type. → **Turn this beach scene description into a picture.**

## Question 7

1. A single prompt can create content and translate it into another language. → **Yes**
2. An output can be translated into another language in the next prompt. → **Yes**
3. Content has to be generated in the same language as its prompt before it can be translated. → **No**

As a single prompt can create content and translate it into another language, content does not need to be generated in the same language as its prompt before it can be translated.

## Question 8

**Correct answers:** Show the number of trees on each continent in a chart format; Show the number of trees on each continent in a table format.

A chart or table gives an easy-to-read summary of the data. Formatting the data into a bulleted or numbered list won't necessarily summarize the data and make it easier to read.

## Question 9

1. What is in the background of this image? → **Yes**
2. Generate a green background for the image of the camera. → **No**
3. Build a similar image using the background of this image. → **No**

Both "No" statements generate content. Neither statement describes content.

## Question 10

1. Producing an image for a specific purpose. → **Show a picture of two cabins in the mountains.**
2. Exploring artistic ideas. → **Show a watercolor portrait of a woman and her golden doodle.**
3. Transforming an image. → **Portray this picture as if it is later in the afternoon.**

## Question 11

1. The character should lip-sync to the text. → **Yes**
2. The character should have gestures according to the script. → **Yes**
3. The character should convey complex emotions during the video. → **No**

A prompt description that is too complex or too vague will not make for a good video of an avatar reading a script.

## Question 12

1. Interpolating between images. → **Create a video that transforms the sunrise image to the sunset image.**
2. Generating a video from a prompt. → **Create a video showing a beach and a sunny sky with light clouds.**
3. Removing an object from a video. → **Delete the surfer from the existing video.**

## Question 13

**Correct answers:** A font that is easy to read; An accurate transcription.

A prompt for automatic subtitles should not include any rewrites, nor should the mood of the speaker be conveyed, as doing so can lead to inaccuracies in the transcription.

## Question 14

**Correct answer:** Colorize the video, using accurate colors for the sky and grass, skin tones, and clothing colors kids usually wear.

The more detail provided, the more accurate the colorized video. Just asking for the video to be colorized risks inaccuracies. Asking for color tones may give a result similar to black and white with a tone, like sepia. Specifying only certain parts will leave the video partly black and white.

## Question 15

**Correct answer:** Animate the image of the mountains from left to right.

A prompt telling an image to move or animate is suitable for turning an image into a video. A prompt telling a Generative AI tool to create a video is not the same as turning an image into a video. Using two images to create a video is an example of interpolating between images. Adding an object to an existing video is not the same as turning an image into a video.
