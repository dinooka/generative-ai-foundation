# Answer Key

## Question 1

**Correct answers:** A powerful GPU; A robust power supply

A server that runs generative AI image models needs a robust power supply and a powerful graphics card unit (GPU), since those two pieces are crucial to training a model. A server's CPU and amount of RAM are not as important, because with image models the GPUs do most of the modeling work.

## Question 2

1. Image models are trained on text-image pairs that can be tagged manually. → **Yes**
2. Image models are trained on text-image pairs that can be tagged automatically with the use of machine learning. → **No**
3. Image models are trained solely using large datasets of other images to learn rules. → **No**

Image models are trained using large datasets and related text to learn rules.

## Question 3

**Correct answer:** LLM

Large Language Models (LLMs) use large amounts of training data to formulate AI-generated content. BERT is used to understand the context of words in searches. T5 makes all natural language processing (NLP) tasks text-to-text. OpenAI Codex is used to generate programming code.

## Question 4

1. LLMs can automate repetitive internal processes. → **Yes**
2. LLMs are trained on huge datasets. → **Yes**
3. LLMs are completely fact-based. → **No**

LLMs use so much data that there will be differing opinions and points of view on the content they generate.

## Question 5

1. OCR → Input: **Image**, Output: **Text**
2. Talking-head → Input: **Audio**, Output: **Video**

Optical Character Recognition (OCR) generates text from text on images. Talking-head generation models use audio to generate video.

## Question 6

1. A narration that turns into a character voicing the narration. → **Audio-to-video**
2. Speaking into a foreign language app and seeing a translation. → **Audio-to-text**
3. Transcribing a video. → **Video-to-text**
4. Typing a phrase and generating a picture. → **Text-to-image**

## Question 7

**Correct answer:** Text-to-text

## Question 10

**Correct answers:** Getting a research question answered using Siri; Sending a reminder based on appointments in a personal calendar in Outlook

Displaying staffing needs based on trends in foot traffic is an example of predictive AI. Suggesting a medication combination based on test results is an example of prescriptive AI.

## Question 11

**Correct answers:** Cost; Ease of use

Ease of use and cost are factors to consider when selecting a tool for generative AI purposes. Marketing and competition are considerations for what outputs generate, not for tool selection itself.

## Question 12

1. Generates multiple social media posts, given some information. → **Meta GPT**
2. Generates banners and flyers as part of a set of promotional graphics. → **Adobe Express**
3. Generates technical documentation based on APIs. → **Claude**

Adobe Express creates graphic design documents, including flyers, banners, and social media images. Claude generates technical documentation based on Application Programming Interface (API) information.

## Question 13

**Correct answer:** The current data can become obsolete.

Rapidly changing data does not mean the data is always current, since an LLM needs to be retrained before its dataset is current. It also does not change output that has already been created, and it does not necessarily slow down output generation.

## Question 14

**Correct answer:** Privacy settings

Privacy settings on data help ensure that conversations not meant to be in an AI model are not used to train the model. Sentiments indicate whether conversations are positive or negative. Data cleaning removes irrelevant and redundant information. Hyperparameters control training samples, how many times they pass through a model, and how quickly a model updates its parameters.

## Question 15

**Correct answers:** Output is not always reliable; There is a lack of universal standards for how AI should be used

The amount of data entered into an AI model and the amount of data generated by an AI model are not limited to any given number of records.

## Question 16

1. High-speed internet. → **Yes**
2. High-end GPUs. → **Yes**
3. A small amount of data. → **No**

Generative AI requires a lot of electric power, a high-speed internet connection to access data, and as many Graphics Processing Units (GPUs) as possible to run AI models efficiently. A small amount of data is often not enough of a sample set to generate accurate output.

## Question 17

1. Output that favors people of a certain socio-economic status. → **Bias**
2. Output that presents false information as factual. → **Misinformation**
3. Output not based on training data or similar knowledge. → **Hallucination**

## Question 18

**Correct answer:** D. Transformer models structure and generate outputs based on tokenized input prompts.

## Question 19

**Correct answer:** B. A block of random noise that looks like TV static, which they refine step by step.

## Question 20

1. Create a character in a video game. → **Generative AI**
2. Estimate next year's sales based on this year's sales. → **Predictive AI**
3. Assigns skiers to groups for lessons based on ability. → **Discriminative AI**
4. Helps a clothing store determine patterns on sales. → **Analytical AI**
5. Helps conduct risk assessments on road projects. → **Statistical AI**

- Generative AI is used to generate content, such as creating a character in a video game.
- Predictive AI is used to predict data, such as estimating next year's sales from existing sales data.
- Discriminative AI is used to categorize data, such as assigning skiers to groups based on ability.
- Analytical AI is used to analyze data, such as discovering purchasing patterns that help a clothing store decide what promotions to run.
- Statistical AI is used to understand data, such as determining risk assessment on road projects.

## Question 21

**Correct answer:** A. A house that is added to a photo after being described.

A house added to a photo after being described is an example of Generative AI. Knowing how much staffing is needed for a publicity event is a result of predictive AI. Classifying feedback as positive or negative is an example of discriminative AI. Detecting an anomaly in sales for a drink is an example of analytical AI.
