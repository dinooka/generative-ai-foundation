# Topic 3B: Types of Prompts

> Study notes summarized in our own words. Not verbatim course text. Single scrollable page.

## Key points
- Advanced prompting is framed as both art and science — assembling the right "ingredients" for the desired result.
- Six core techniques (domain 3.3): **zero-shot**, **few-shot**, **chain-of-thought**, **self-consistency**, **generated knowledge**, **prompt chaining**.
- **Zero-shot prompting:** no examples or context given — best for creative exploration (e.g., futuristic city description, science-fair ideas, what-if scenarios).
- **Few-shot prompting:** provide a handful of examples as reference points so the model picks up the style, structure, and tone; a few relevant examples suffice.
- **Chain-of-thought prompting:** ask for step-by-step logical reasoning — useful for math, historical analysis, and creative writing.
- **Consistency:** keep style, facts, and tone steady across outputs (storytelling, academic writing, chatbots); self-consistency techniques improve reliability.
- **Generated knowledge prompting:** first gather facts, then summarize — a two-step gather-then-synthesize pattern.
- **Prompt chaining:** break complex tasks into connected prompts, using conditional "if...then" logic (storytelling pipelines, customer-service flows, virtual assistance).
- Supporting inputs (domain 3.2): glossaries for translation (e.g., legal terms), templates (e.g., product-recall email), research documents for grounding (supply articles for the model to work from — retrieval-style), and conversation memory (earlier turns in the same thread).
- Embedded knowledge checks appear after sections.

## Key terms
zero-shot prompting, few-shot prompting, chain-of-thought reasoning, self-consistency, generated knowledge prompting, prompt chaining, pattern recognition, model learning, glossary for translation, domain-specific content, templates, context grounding, retrieval augmented generation (RAG), conversation memory.
