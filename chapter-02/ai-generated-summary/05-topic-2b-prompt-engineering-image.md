# Topic 2B: Prompt Engineering for Image Generation and Analysis

> Study notes summarized in our own words. Not verbatim course text. Single scrollable page.

## Key points
- Image generation starts from a text prompt that must specify the intended style and content.
- Eight elements of a strong image prompt: content details, style choice, color preferences, emotion/mood, composition tips, perspective clues, scene setting, and unique elements.
- Purpose-driven image creation: marketing materials, illustrations, and concept art each need different prompt emphases.
- Refining image prompts: iterate in rounds, use reference images, combine elements, add unique details, control layout, and try a **multi-tool approach**.
- Advanced controls: aspect ratio (–AR), **seed number** (–seed) for reproducibility, style prompts (–style), resolution (–res), depth of field (–DOF).
- Image transformation: style transfer, adding/removing objects, changing scenes; caution against unethically copying small creators' signature styles.
- Artistic exploration: using prompts to brainstorm and iterate on creative ideas.
- AI and accessibility: generating alt text and describing image content improves access for visually impaired users and boosts SEO.
- Embedded knowledge checks appear after sections.

## Key terms
image generation, image prompt, style choice, composition, perspective, seed number, aspect ratio, image transformation, object manipulation, automated image editing, image restoration, image analysis, image description, multi-tool approach, test and tweak, multiple options generation.
