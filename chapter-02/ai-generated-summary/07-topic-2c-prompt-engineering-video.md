# Topic 2C: Prompt Engineering for Video Creation and Transformation

> Study notes summarized in our own words. Not verbatim course text. Single scrollable page.

## Key points
- Seven video objectives: adding motion to images, interpolating between images, colorizing black-and-white footage, generating video from a prompt, avatar reading a script, adding/removing objects, automated subtitling.
- **Adding motion:** subtle animation, camera panning, and object movement; control speed, direction, animation style, and combine multiple motions.
- **Generating video from a prompt:** narrative-driven clips, product ads, educational segments; define visual elements, set style/tone, specify duration/pacing, include audio cues.
- **Interpolation:** cross-dissolve, morphing, and slide transitions between frames; define start/end frames, style, and timing/duration.
- **Colorization:** basic color fill, mood-based palettes, and historically accurate coloring of B&W footage.
- **Script-driven avatars:** virtual presentations, educational explainers, entertainment; describe appearance, voice/accent, emotional expressions, and script context.
- **Localized editing:** adding objects requires matching identity, placement/scale, lighting, and motion consistency; removing objects (static, moving, watermarks) serves film/TV, marketing, and content repurposing.
- **Automated subtitling:** basic captions, multilingual subtitles, and accessibility subtitling; set language/formatting, differentiate speakers, and sync timing.
- Embedded knowledge checks appear after sections.

## Key terms
AI animation, image interpolation, AI colorization, AI video generation, AI avatar generation, video script generation, AI object removal, object manipulation, AI automated subtitling, specialized language processing, AI translation.
