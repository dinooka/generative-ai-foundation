# Chapter 2: Vocabulary

> Study notes summarized in our own words. Not verbatim course text.
> The in-course item is an interactive H5P flashcard deck whose card text is not exposed; the terms below are the chapter's official Key Terms, defined in our own words.

- **Tokens** — the small text units (word parts, punctuation) a model actually reads and predicts.
- **Artificial General Intelligence (AGI)** — hypothetical AI with broad, human-level capability across many domains.
- **Large Language Model (LLM)** — a massive neural model trained on huge text collections for language tasks.
- **Hallucination** — confident but false content invented by the model.
- **Prompt Refinement** — iteratively improving a prompt to get better output.
- **Custom GPT** — a tailored chatbot with fixed instructions, tone, and knowledge for a specific use.
- **Stochastic** — involving randomness; the same prompt can yield different outputs.
- **Emergence** — unexpected capabilities that appear as models scale up.
- **Constraints** — limits placed in a prompt (format, length, tone) to steer the output.
- **Content Gathering** — using prompts to collect facts, statistics, and background information.
- **Content Transformation** — reshaping existing content (reformat, edit, translate, change medium).
- **Prompt Specificity** — how detailed and precise a prompt is.
- **AI-Assisted Editing** — using AI tools to revise and polish writing.
- **Grammatical Error Detection** — AI spotting grammar mistakes in text.
- **Sentence Structure Improvement** — AI reworking sentences for clarity and flow.
- **Content Visualization** — turning text into visual forms (bullets, charts, flowcharts).
- **Audio Summarization** — condensing spoken/audio content into a shorter summary.
- **Image Description** — AI-generated textual account of an image's content.
- **Video Script Generation** — AI drafting scripts/narration for videos.
- **AI Translation** — converting text between languages with AI.
- **Image Generation** — creating images from text prompts.
- **Multiple Options Generation** — asking the model to produce several alternatives at once.
- **Test and Tweak** — trying a prompt, reviewing the result, and adjusting iteratively.
- **Multi-Tool Approach** — combining several AI tools to complete one task.
- **Seed Number** — a setting that makes image generation reproducible across runs.
- **Image Transformation** — altering an existing image (style, objects, scene).
- **Object Manipulation** — adding, removing, or editing objects within an image.
- **Image Restoration** — repairing or enhancing damaged/old images.
- **Automated Image Editing** — AI-driven edits (retouching, background changes) with minimal manual work.
- **Image Analysis** — AI examining an image to identify its contents.
- **AI Animation** — adding motion to still images or generating animated sequences.
- **Image Interpolation** — creating transitional frames between two images.
- **AI Colorization** — adding color to black-and-white photos or footage.
- **AI Video Generation** — producing video clips from text prompts.
- **AI Avatar Generation** — creating virtual characters that speak a script.
- **AI Object Removal** — erasing unwanted elements from images or video.
- **AI Automated Subtitling** — generating synchronized captions/subtitles for video.
- **Specialized Language Processing** — AI tuned for domain-specific language tasks (e.g., subtitling, translation).
